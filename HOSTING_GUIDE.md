# 🚀 Free Hosting Guide for Praveen & Janani's Engagement Invitation

You can host this interactive invitation website **100% FREE forever** without paying a single rupee or writing any code.

---

## 🌟 Method 1: Netlify Drop (Easiest — Takes 60 Seconds!)

**No coding or installation needed! Just drag and drop.**

1. Open your browser and go to: **[https://app.netlify.com/drop](https://app.netlify.com/drop)** (Sign up for a free account if asked).
2. Open your File Explorer and find this folder on your computer:
   ```
   C:\Users\akash\.gemini\antigravity\scratch\engagement-invitation
   ```
3. **Drag and drop the `engagement-invitation` folder** directly onto the Netlify webpage.
4. **Done!** Netlify will immediately give you a live public link (e.g., `https://random-name.netlify.app`).
5. *(Optional)* **Change link name to something custom:**
   - Click **"Site configuration"** (or **"Site settings"**).
   - Click **"Change site name"**.
   - Type `praveen-weds-janani` or `praveen-janani-engagement`.
   - Your final link will look like: **`https://praveen-janani-engagement.netlify.app`**!

## 🌟 Method 2: GitHub Pages (Permanent & Reliable)

1. Go to **[https://github.com](https://github.com)** and log in / create a free account.
2. Click **"+" (top right) -> "New repository"**.
3. Name it `engagement-invitation` and make sure it is set to **Public**. Click **"Create repository"**.
4. Click **"uploading an existing file"**.
5. Select and upload all the files inside `engagement-invitation`:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets/` folder
6. Click **"Commit changes"**.
7. Go to **Settings -> Pages (on the left menu)**.
8. Under **"Branch"**, select **`main`** and folder **`/(root)`**, then click **Save**.
9. In about 1 minute, your website will be live at:
   **`https://<your-github-username>.github.io/engagement-invitation/`**

## 🌟 Method 3: Vercel

1. Go to **[https://vercel.com](https://vercel.com)** and log in with GitHub or email.
2. Drag & drop the project folder or import from GitHub.
3. Click **Deploy**.
4. Your website is instantly live at **`https://praveen-janani-engagement.vercel.app`**.
